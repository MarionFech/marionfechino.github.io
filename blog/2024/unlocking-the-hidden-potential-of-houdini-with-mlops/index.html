Recently, I encountered new challenges and decided to experiment with Houdini from SideFx. Houdini is a node-based 3D software widely utilized for creating visual effects in films and TV series. It facilitates robust procedural workflows and provides functionality for users to create, share, and sell their tools.

Today, I want to focus on one such tool called MLOPs (Machine Learning Operators), which has recently gained popularity within the Houdini community. I’ll walk you through my workflow for generating Stable Diffusion images and share some neat tricks you can employ to create a seamless progression of images with consistent themes or styles.

After following the installation instructions provided on the MLOPs GitHub page, I’ve configured the following base MLOPs scene within a Geometry node to produce an image from a text prompt, utilizing the default MLOPs Stable Diffusion 1.5 model.

In our setup, we’ve configured the seed to be determined by the current frame value ($F). This approach enables us to efficiently generate variations of the image our Stable Diffusion model produces simply by playing through the frame range.

A neat trick that could be employed after generating the initial image is to input the previously generated image into the second “sd text encoder” node and constrain the model hyperparameters to utilize it for generating the following image.

Animating the ‘Hue Shift’ and allowing the model to run for 70 frames resulted in this output.
